# 圣杯布局

圣杯布局（Holy Grail Layout）是前端里一个经典三栏页面布局方案：

1. 中间主内容区 main 最先渲染（在 HTML 结构里靠前）

2. 左右是固定宽度侧边栏（left / right）

3. 中间区域自适应，占满剩余空间

4. 常见于“顶部导航 + 三栏主体 + 底部”的网站结构

### 核心目标

- 主内容优先（SEO 和可读性更好）

- 两侧固定，中间弹性

- 整体结构稳定，适配不同屏宽

### 传统实现（早期）

- float + 负外边距 + relative

- 实现复杂、维护成本高

## 新式实现（现代）

- Flex 或 Grid 非常容易实现

- 例如 Grid: 200px 1fr 200px 就是典型圣杯三栏

### “双飞翼布局”区别（常见面试点）

- 两者目标相似，都是三栏+主内容优先

- 圣杯布局通常通过给容器加左右 padding 再配合负边距定位侧栏

- 双飞翼布局通常在中间列再包一层内部容器，用 margin 给两侧让位
